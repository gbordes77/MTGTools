MTGOSDK: Proof it's possible

MTGOSDK : La preuve que c'est possible

Our first technical building block already reads MTGO memory in real-time.

Notre première brique technique lit déjà la mémoire MTGO en temps réel.

MTGOSDK

FUNCTIONAL FONCTIONNEL

C# SDK that extracts all MTGO client data in real-time: cards, matches, events, collection. The foundation for building any tool.

SDK C# qui extrait en temps réel toutes les données du client MTGO : cartes, matchs, événements, collection. La base pour construire n'importe quel outil.

// Installation
dotnet add package MTGOSDK

// Usage
var client = new MTGOClient();
var collection = client.GetCollection();
var currentMatch = client.GetCurrentMatch();
