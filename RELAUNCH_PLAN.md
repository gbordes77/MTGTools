```
Talents Techniques × Compétiteurs = Performance Maximale
```

## 5 RAISONS DE LANCER

1. **Le site est enfin bon** - Plus de promesses vides, message clair de co-création
2. **Le cold start ne sera jamais plus facile** - 100+ utilisateurs Videre qui attendent
3. **Marché inoccupé** - 200K joueurs compétitifs, 40% dans la tech, aucune communauté équivalente
4. **Moment stratégique** - Nouvelle saison Magic = joueurs qui cherchent des outils
5. **Le perfectionnisme est l'ennemi** - Tout est prêt, il manque juste l'action

## PLAN D'ACTION 7 JOURS

### JOUR 1 - PRÉPARATION FINALE

**Matin (2h)**
- [ ] Vérifier que tous les canaux Discord sont bien configurés
- [ ] Épingler le manifeste dans #welcome et #charter
- [ ] Configurer le bot de bienvenue avec message personnalisé
- [ ] Tester le parcours d'un nouveau membre de A à Z

**Après-midi (2h)**
- [ ] Poster 3-5 messages de seed dans chaque canal principal
- [ ] Préparer le message d'invitation pour tes contacts directs
- [ ] Lister 10 personnes de ton réseau à inviter personnellement

### JOUR 2 - NOYAU FONDATEUR

**Objectif : 5-10 membres fondateurs actifs**

- [ ] Envoyer des invitations personnelles à 10 contacts proches
- [ ] Appeler/texter les 3-5 personnes les plus importantes
- [ ] Créer le rôle @Founding-Member avec badge spécial
- [ ] Organiser une conversation informelle dans #general-chat
- [ ] Premier message vocal dans un channel voice

### JOUR 3 - ACTIVATION VIDERE

**Objectif : Migrer les utilisateurs Videre les plus actifs**

- [ ] Poster une annonce dans l'application Videre (si possible)
- [ ] Envoyer un message aux contributeurs GitHub Videre
- [ ] Créer #videre-transition pour accueillir les migrants
- [ ] Offrir le rôle @Early-Adopter aux 20 premiers de Videre
- [ ] Première session "Office Hours" de 30min en voice

### JOUR 4 - CONTENU VALEUR

**Objectif : Démontrer la valeur concrète**

- [ ] Poster une première analyse meta dans #metagame
- [ ] Partager un snippet de code MTGOSDK avec explication
- [ ] Lancer un sondage : "Quel outil vous ferait gagner des points ?"
- [ ] Documenter une feature de Videre en temps réel
- [ ] Répondre publiquement à chaque message

### JOUR 5 - EXPANSION SÉLECTIVE

**Objectif : 25-30 membres**

- [ ] Post sur r/MTGO avec valeur réelle (pas de pub vide)
- [ ] Contacter 2-3 streamers MTGO pour leur montrer Videre
- [ ] Inviter des devs Magic de réputation
- [ ] Première annonce Twitter/X avec lien Discord
- [ ] Créer une liste des features demandées

### JOUR 6 - CONSOLIDATION

**Objectif : Routine quotidienne établie**

- [ ] Poster le premier "Meta Monday"
- [ ] Organiser une session de pair-programming en voice
- [ ] Identifier 2-3 membres potentiels modérateurs
- [ ] Documenter les premières interactions dans #success-stories
- [ ] Message de remerciement personnel aux plus actifs

### JOUR 7 - ÉVALUATION

**Objectif : 40+ membres, activité quotidienne**

- [ ] Compter les membres, messages, et interactions
- [ ] Identifier ce qui fonctionne vs ce qui ne prend pas
- [ ] Ajuster la structure si nécessaire
- [ ] Planifier la semaine 2 avec les retours
- [ ] Célébrer les victoires publiquement
