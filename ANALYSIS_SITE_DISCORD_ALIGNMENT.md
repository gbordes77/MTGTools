## 2. Analyse du Site Web

### 2.1 Proposition de Valeur

**Formule signature** (ajoutée le 27/12/2025):
- EN: "Technical Talents × Competitive Players = Maximum Performance"
- FR: "Talents Techniques × Compétiteurs = Performance Maximale"

**Les 3 Piliers**:
1. **Your needs first** - Les joueurs expriment leurs problèmes, la communauté développe
2. **Fully open source** - MIT license, transparence, contributions bienvenues
3. **Data-driven** - Décisions basées sur des données réelles


- Contribuer au code existant
- Proposer de nouveaux outils
